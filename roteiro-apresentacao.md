# Roteiro de Apresentação - IFPI Organiza

## 1. Abertura

Bom dia/boa tarde. O projeto apresentado é o IFPI Organiza, uma proposta de aplicativo mobile para ajudar alunos do IFPI a organizarem tarefas acadêmicas, provas, trabalhos e prazos do curso.

## 2. Problema

Durante o semestre, os alunos precisam acompanhar várias disciplinas e diferentes datas de entrega. Muitas vezes essas informações ficam espalhadas em mensagens, anotações ou cadernos, o que pode causar esquecimento e atraso.

## 3. Solução proposta

A solução proposta é um aplicativo simples, com foco em organização acadêmica. O aluno pode visualizar suas tarefas, acompanhar prazos, cadastrar novas atividades e marcar o que já foi concluído.

## 4. Principais telas

- **Login:** simula a entrada do aluno no aplicativo.
- **Início:** mostra o resumo de tarefas pendentes, concluídas e o próximo prazo.
- **Tarefas:** lista as atividades cadastradas.
- **Nova tarefa:** permite simular o cadastro de uma atividade.
- **Prazos:** mostra um calendário simplificado com datas importantes.
- **Perfil:** apresenta dados básicos do aluno e do projeto.

## 5. Tecnologias

Nesta etapa foram utilizadas tecnologias simples para prototipação:

- HTML5
- CSS3
- JavaScript
- VS Code

## 6. O que existe nesta etapa

Nesta fase existe um protótipo mobile navegável, rodando no navegador. A navegação é simulada, os dados ficam em um array JavaScript e não há backend ou banco de dados real.

## 7. O que fica para implementação futura

Em uma próxima etapa, o projeto pode ser implementado como aplicativo mobile real usando React Native ou Flutter. Também pode receber autenticação, banco de dados com Firebase ou Supabase e notificações de prazos.

## 8. Encerramento

O IFPI Organiza busca apoiar a organização acadêmica de forma simples e prática. A proposta inicial mostra como o aplicativo pode funcionar e serve como base para uma implementação futura.

## 9. Possíveis perguntas e respostas

**O aplicativo já salva dados de verdade?**  
Não. Nesta etapa os dados são simulados no JavaScript, pois o foco é o protótipo e o design do MVP.

**Por que criar um app para tarefas acadêmicas?**  
Porque os alunos lidam com muitos prazos e disciplinas, e uma ferramenta simples pode ajudar na organização da rotina.

**Quais tecnologias seriam usadas na versão final?**  
React Native ou Flutter para o aplicativo mobile, Firebase ou Supabase para autenticação e banco de dados, e GitHub para versionamento.

**O protótipo funciona no celular?**  
Ele foi pensado com layout mobile e pode ser aberto no navegador. A versão atual simula a aparência de um app em uma tela de celular.
