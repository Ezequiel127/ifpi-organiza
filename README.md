# IFPI Organiza

IFPI Organiza é um protótipo mobile de MVP voltado para alunos do IFPI organizarem tarefas acadêmicas, provas, trabalhos e prazos do curso.

O projeto faz parte da etapa de Projeto e Design da disciplina Programação para Dispositivos Móveis - ADS 4 - 2026.1. Nesta fase, o objetivo é apresentar a ideia, a navegação principal e a aparência inicial do aplicativo, sem backend ou banco de dados real.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- VS Code

## Funcionalidades simuladas

- Tela de login
- Dashboard com resumo de tarefas
- Lista de tarefas acadêmicas
- Cadastro de nova tarefa
- Marcação de tarefa como concluída
- Tela de prazos em formato de calendário
- Perfil simples do aluno

## Como abrir o protótipo

Abra o arquivo `index.html` em um navegador. O protótipo roda localmente e utiliza dados simulados no próprio arquivo `script.js`.

## Observação

Esta versão representa um protótipo navegável para apresentação acadêmica. A implementação futura poderá utilizar React Native ou Flutter, Firebase ou Supabase e versionamento com GitHub.
