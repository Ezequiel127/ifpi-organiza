# Instruções do Projeto - IFPI Tasks

Este projeto é um protótipo mobile de MVP para a disciplina Programação para Dispositivos Móveis - ADS 4 - 2026.1.

## Objetivo

Criar uma proposta de aplicativo mobile chamado "IFPI Tasks", voltado para alunos do IFPI organizarem tarefas acadêmicas, prazos, provas, trabalhos e atividades do curso.

## Escopo da etapa atual

Esta etapa é de Projeto e Design, não de implementação completa.

O projeto deve conter:
- protótipo mobile navegável em HTML, CSS e JavaScript;
- documentação do MVP;
- roteiro de apresentação;
- README explicando o projeto.

## Estilo visual

Usar visual moderno, limpo e acadêmico:
- fundo claro;
- cards brancos;
- detalhes em verde institucional;
- layout mobile;
- fonte simples;
- boa legibilidade;
- aparência de app real.

## Regras importantes

- Não mencionar que o projeto foi feito por IA.
- Não inserir comentários como "gerado por IA".
- Usar textos naturais, objetivos e acadêmicos.
- Manter o projeto simples e fácil de apresentar.
- Priorizar clareza sobre complexidade.
- O protótipo deve simular um app mobile, mesmo rodando no navegador.
- O código deve ser simples, sem frameworks pesados.
- Não usar backend real.
- Não usar banco de dados real nesta etapa.
- Os dados podem ser simulados no próprio JavaScript.

## Tecnologias escolhidas para o protótipo

- HTML5
- CSS3
- JavaScript
- VS Code

## Tecnologias previstas para implementação futura

- React Native ou Flutter para o app mobile
- Firebase ou Supabase para autenticação e banco de dados
- GitHub para versionamento
